## Comparison

The implementation matches the reference's persistent scientific-workspace header, compact navigation, two-column analysis layout, compound confirmation panel, prediction status strip, category cards, export controls, raw response disclosure, and full-width disclaimer. The captured desktop image was compared at full resolution; the same capture also provides focused evidence for the header, compound workspace, prediction cards, and footer because those regions are all legible at native resolution.

Batch Screening matches the reference hierarchy: persistent navigation, a
four-step status strip, actual processed/total progress, compact job facts, six
validation metrics, an internally scrolling results table, selected-compound
preview, exports, and disclaimer. The captured state came from a file uploaded
through the interface, not from screenshot values.

Model Information matches the overview, endpoint catalog, detail panel, and
supporting information rail. Status and endpoint rows come from the backend;
unreported model versions and unverified units stay explicitly unavailable.

## Iterations

1. Initial mobile capture exposed a P2 issue where the third navigation item was clipped.
2. Mobile navigation was changed to three equal-width links with constrained labels.
3. Desktop and mobile captures were regenerated after the fix. No horizontal overflow or clipped navigation remains.
4. Batch capture initially preceded the RDKit preview; capture now waits for the live structure.
5. Model catalog/detail panels were stretched to the support-rail height to remove a P2 desktop whitespace imbalance.

## Intentional differences

- The tested state shows `Mock Predictions`, not `Real ADMET-AI`, because visual QA must remain deterministic and must not imply that mock values came from the real model.
- Endpoint names, counts, values, and summary text come from the API response. Scientific values from the reference image are not embedded in the UI.
- The molecular depiction is generated by RDKit, so bond orientation differs from the illustrative reference while representing the resolved molecule.
- Unverified units and endpoint metadata are omitted or labeled conservatively.
