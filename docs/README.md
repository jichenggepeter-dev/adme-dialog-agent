## Historical documents

Files named `plan`, `report`, `review`, `audit`, `handoff`, or `current-state`
record implementation decisions at a point in time. They may describe older
behavior and are not normative product contracts.

When historical notes conflict with current code, tests, the project
positioning, or the current reference documents above, treat the historical
note as archival evidence rather than current behavior.
