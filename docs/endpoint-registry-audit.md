## Fields currently under Other

Fifty fields are placed under Other. They comprise the physicochemical and
drug-likeness fields, alerts, Tox21 and carcinogenicity outputs, hydration free
energy and AstraZeneca lipophilicity, plus their corresponding DrugBank
percentiles. This is caused by keyword grouping rather than registry metadata.

## Naming and alias findings

- Existing keys use `raw_key`; the proposed schema uses `raw_name`.
- No aliases are currently supported.
- Case, spaces, underscores, and hyphens are not normalized.
- Substrate and inhibitor distinctions are preserved only accidentally by raw
  string matching; normalization must never remove those scientific tokens.
- Percentiles are generated by appending the exact package-defined
  `_drugbank_approved_percentile` suffix to each base task.

## Incorrect or incomplete metadata

- ADMET-AI calls classification outputs probabilities in its bundled official
  interface, but current entries use the ambiguous label `classification`.
- RDKit-computed molecular weight, LogP, H-bond counts, stereo-center count,
  TPSA, QED, Lipinski rules satisfied, and alert counts are not model regression
  outputs even though the package CSV uses a generic `regression` task label.
- Units are hidden for every endpoint, including package-documented units.
- `HydrationFreeEnergy_FreeSolv` and `Lipophilicity_AstraZeneca` fall under Other
  even though the package categorizes them as absorption tasks.
- Tox21 and carcinogenicity endpoints fall under Other instead of toxicity.

## Unsafe summary behavior

`app/formatter.py` currently treats any numeric value in `[0, 1]` as a low,
moderate, or high predicted probability unless its key matches a small
regression-hint list. This can mislabel QED, arbitrary descriptors, unknown
outputs, and other bounded numerical values. Summary generation does not check
metadata status, output type, positive-class semantics, percentile reference
set, or language permissions.

## Migration plan

1. Introduce a versioned registry loader grounded in ADMET-AI 2.0.1 bundled
   metadata, with a non-throwing unknown fallback.
2. Add exact, explicit-alias, and conservative formatting-normalized matching.
3. Represent descriptors, counts, rule-derived values, classification
   probabilities, regressions, and DrugBank percentiles separately.
4. Generate enriched endpoint results without mutating raw predictions.
5. Make category grouping registry-first and add physicochemical,
   drug-likeness, and benchmark categories.
6. Gate summary probability and percentile language on verified metadata.
7. Expand `/endpoints`, endpoint detail, and add `/endpoints/coverage`.
8. Update Single, Batch, and Model Information rendering and add regression,
   matching, provenance, safety-language, and fallback tests.
