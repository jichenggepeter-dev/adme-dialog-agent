# Batch and About Design Decisions

The supplied images define the hierarchy and density: compact persistent header,
stepper and progress strip, left job facts, center table, right compound preview,
top model facts, endpoint catalog/detail split, and supporting information rail.

Production data replaces every screenshot example. The batch page begins with a
real upload state instead of a pre-populated job. Mock mode uses amber disclosure.
RDKit supplies structures. Unverified units are omitted. Comparison is neutral
and never declares a preferred compound. Tables scroll internally so the page
does not overflow on small screens.
