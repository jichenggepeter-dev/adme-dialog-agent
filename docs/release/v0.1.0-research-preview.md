# v0.1.0 Research Preview

Release date: 2026-08-08

ADME Dialog Agent v0.1.0 is a local-first, open-source research preview for
exploring computational ADME/ADMET predictions. It combines a visual workflow
with a constrained Assistant while keeping scientific interpretation and
higher-impact actions under human control.

This is a software research preview. It is not clinical software, a validated
scientific model release, a production service, or evidence that a compound is
safe, effective, or preferable to another compound.

## Included in this preview

- Single-molecule and bounded Batch workflows with explicit structure
  confirmation before prediction.
- Deterministic Mock prediction and Mock Agent paths that require no provider
  credential and remain visibly labeled as test data.
- One allowlisted Agent with typed page context, bounded tools, single-use
  confirmations, stable errors, and local redacted audit events.
- Versioned NDJSON response streaming with visible progress, activity, evidence,
  confirmation, completion, cancellation, and error states.
- A small citation-grounded FDA evidence corpus with reproducible retrieval,
  visible source cards, and explicit insufficient-evidence behavior.
- Session-owned JSON or Markdown export with a versioned JSON schema and
  explicit inclusion and exclusion rules.
- Confirmed, atomic deletion of one Assistant session and its owned local state.
- Contributor governance, security reporting, license boundaries, secret-free
  CI, clean-clone instructions, and course demonstration evidence.

## Human-control and privacy boundaries

- Prediction, Batch execution, export, and deletion require explicit approval.
- A confirmation or pending action is session-owned, expiring, hash-bound, and
  single-use. Replays and stale state are rejected.
- Sessions, resources, audit records, uploads, jobs, and results are local by
  default. The project collects no product telemetry by default.
- Direct SMILES and Mock workflows can remain local. Compound name or PubChem
  CID resolution may contact PubChem. An enabled external Agent provider
  receives only the documented bounded context.
- API keys, authorization values, internal prompts, complete provider bodies,
  and full Batch data are excluded from user-facing activity and session
  exports.

## Known limitations

- The default demonstration uses deterministic Mock prediction and Agent data.
- The evidence corpus is intentionally small and cannot answer arbitrary
  scientific questions.
- A bare Agent `session_id` is a local capability, not multi-user
  authentication. The service is intended for one user on loopback only.
- SQLite persistence and local Batch files are development infrastructure, not
  a durable multi-user data service.
- Real ADMET-AI execution has larger optional dependencies and separate model,
  training-data, and reference-data rights that are not covered by the
  project's MIT license.
- DrugBank and other third-party data remain subject to their own terms. This
  repository does not grant redistribution rights for external models or data.
- Automated accessibility regression coverage and the broader Agent evaluation
  suite remain v0.2 work.

## Deliberately out of scope

- clinical, treatment, dose, regulatory, safety, efficacy, or candidate-ranking
  conclusions;
- production deployment, accounts, shared tenancy, or cloud synchronization;
- arbitrary document upload, automatic paper crawling, or unrestricted web
  research;
- GraphRAG, autonomous loops, multi-Agent orchestration, arbitrary code, shell,
  file, MCP, or hosted-tool execution.
