# Model Information Page

`/about` combines actual `/status` and `/endpoints` responses. It reports mode,
availability, initialization state, backend version, runtime, input type, and
only model metadata the backend can verify. Missing model versions and dates are
shown as not reported or not initialized.

The endpoint catalog supports search, category/type filters, verified-only
filtering, pagination, and a registry-backed detail panel. Supporting panels
explain mock/real modes, implementation data-source responsibilities, scientific
scope, and defensible limitations.
